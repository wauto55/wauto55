# WAuto — полноценный многостраничный сайт

Сайт работает как обычный статический многостраничный проект и открывается двойным кликом по `index.html`.

## Основные страницы

- `index.html` — главная
- `models.html` — каталог моделей
- `faults.html` — база неисправностей
- `diagnostics.html` — интерактивная диагностика
- `repair.html` — руководства по ремонту
- `parts.html` — запчасти и инструменты
- `tips.html` — советы

## Отдельные страницы

- 10 страниц моделей: `model-*.html`
- 10 страниц неисправностей: `fault-*.html`
- 5 страниц руководств: `guide-*.html`

Итого: 32 HTML-страницы.

## Архитектура

Содержимое страниц находится непосредственно в HTML. JavaScript отвечает только за интерактив: поиск, фильтры, выбор машины, избранное, чек-лист инструментов и диагностику.

Для запуска сервер не требуется: распакуйте архив и откройте `index.html`.
