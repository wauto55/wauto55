Локальные изображения автомобилей находятся в assets/images/ui/ и выбираются по модели в js/main.js.
Иллюстрации для запчастей и неисправностей подбираются по типу детали/симптому, чтобы изображения не назначались случайно.
Некоторые изображения в js/data.js подключаются с Wikimedia Commons и требуют интернет-соединения. Если источник недоступен, используется assets/icons/image-fallback.svg.


Фотографии обновлены из предоставленного архива «картинки для сайта». Исходные локальные изображения находятся в assets/images/supplied; интерфейсные имена сохранены для совместимости.
